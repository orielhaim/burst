# Burst

An experimental open-source FPS built in public

The project is currently focused on building the core foundations: responsive movement, weapon systems, physics, and first-person feel. Everything is designed to be modular and easy to extend so anyone can contribute new mechanics, weapons, maps, visuals, or ideas

## Current milestone

- Advanced FPS movement
- Procedural character movement
- Extensible weapon system

## Planned

- Multiplayer
- More maps
- More weapons
- Skins and cosmetics
- Game modes
- Community-made content

The long-term goal is a community-driven FPS where the game grows through open contributions rather than a closed development process
